# Use Case: Boilerplate Setup (Core Coding)

## Activity Description
Initializing a new project with the standard tech stack, folder structure, linting rules, and basic configurations.

### Problems & Inefficiencies
- **Repetitive Labor:** Senior devs spend hours setting up the same Next.js/Express/Database scaffolding for every project.
- **Human Error:** Missing a critical environment variable or misconfiguring a linter leads to technical debt early on.
- **Boredom:** Highly skilled engineers are wasted on mundane setup tasks.

## AI-Native Reimagining
Instead of manual setup, we use a "Project Generator" prompt. The developer describes the stack and specific requirements (e.g., "Next.js with Supabase and Tailwind, include Auth and a Stripe hook"), and the AI generates the entire file structure and configuration in seconds.

### Quality & Efficiency Improvements
- **Quality:** Consistent, "clean room" setups every time; reduces configuration drift across agency projects.
- **Efficiency:** 90% reduction in setup time (from hours to minutes).

## AI Tool Selection
- **Primary Recommendation:** **Cursor (AI Code Editor)** - Its "Composer" feature can generate multiple files and folders based on a single natural language instruction.
- **Alternative(s):** **Gemini 1.5 Pro** - Excellent for generating complex, multi-file configuration scripts and shell commands.

### Specific Tool Notes
- Use Cursor's `@Codebase` index to ensure the boilerplate follows Alphonso's specific internal coding standards.

## AI-Integrated Workflow (Operational Steps)
1. **[Human Step]:** Open a fresh directory in Cursor and describe the project stack.
2. **[AI Step]:** Use Cursor Composer or a shell command generated by Gemini to scaffold the directories and create core config files (`package.json`, `.env.example`, `tsconfig.json`).
3. **[AI Step]:** AI generates the basic Auth and Database connection logic based on the PRD.
4. **[Human Step]:** Verify the setup by running `npm install` and `npm run dev`, then commit the initial boilerplate.
