# Code Implementation

**Works on:** 005-prd.md
**Output:** 008-architecture.md

To implement the PRD, generates an architecture for the code. Read the PRD, understand the requirements, and build the architecture.

---

## Process

1. Read 006-prd.md thoroughly to understand:
   - Problem Statement
   - Solution approach
   - User Stories
   - Implementation Decisions
   - Testing Decisions
   - Modules to be built/modified

2. Explore the existing codebase (if present) to understand:
   - Current architecture
   - Module structure
   - Testing patterns and conventions
   - Coding standards
   - Dependencies and constraints

3. Specify the architecture of the project so that code can be generated for this archiecture.

---

## Output

- Details of important classes and functions (not exhaustive, smaller functions or classes can be generated as necessary in the later steps)
- Descriptions of each class, as well as their dependencies and relations to other classes
- Basic description of key member functions and attributes for each class.
- Specific implementation details and strategies to meet constraints
- Specific pitfalls to avoid.

Every point mentioned in the PRD should be reflected and addressed in the architecture.
