# Intent

## The Goal

ABC Ltd. is an organization with multiple departments. We need to make a progress tracker for them.


## Success Looks Like
A progress tracker web app using basic libraries/frameworks like bootstrap. It should have login for managers and employees. It should be connected to supabase as a database. It should be user friendly and professional looking.

## Details
Each department has a set of tasks. Each task is allocated to a person or group of people. Each department has a manager who is in charge of making sure the tasks are completed on time. Tasks should have status like pending, completed, in progress, etc.
