# Brainstorm

**Works on:** 001-intent.md
**Output:** 003-decisions.md

Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree. Use when user wants to stress-test a plan, get grilled on their design, or mentions "brainstorm".

---

Interview relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. Also ask about any technical design considerations that you have doubts about. For each question, provide your recommended answer.

Ask the questions one at a time. Ask MCQ questions, and recommend one option for each question.

If a question can be answered by exploring the codebase, explore the codebase instead.

Based on the answer to each question, record the decisions made in 003-decisions.md.
